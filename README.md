# Portfólio pessoal

Site de portfólio responsivo feito com HTML, CSS e JavaScript puro. Não precisa instalar dependências: abra index.html no navegador ou publique os arquivos em qualquer hospedagem estática.

## Personalização

- Troque Seu Nome, as iniciais SN, o e-mail e os links sociais em index.html.
- Atualize os textos e os projetos de demonstração com seus trabalhos reais.
- Ajuste a paleta no início de style.css.

O layout foi pensado primeiro para telas pequenas e inclui menu móvel, navegação por âncoras, cartões de projeto e links de contato.
