# Marcella Bongiolo — Portfólio

Portfólio pessoal de Marcella Bongiolo, estudante de Engenharia de Software. O site apresenta projetos autorais e descreve cada um conforme o que está implementado nos respectivos repositórios.

**Site publicado:** [marcellabongiolo.github.io/portfolio-app](https://marcellabongiolo.github.io/portfolio-app/)

## Projetos em destaque

- [SLADeck](https://github.com/marcellabongiolo/SLADeck) — MVP multi-tenant para solicitações, responsáveis, prioridades, prazos de SLA, notificações e atividade operacional. Usa Next.js, TypeScript, FastAPI, PostgreSQL, Redis e Celery; não é uma implantação de produção.
- [AgentTrace](https://github.com/marcellabongiolo/AgentTrace) — MVP local/self-hosted com SDK Python, API FastAPI, persistência SQLite e painel Next.js para inspecionar traces, spans, eventos, métricas e erros fornecidos pela aplicação.
- [AI 4D](https://github.com/marcellabongiolo/ai-4d) — protótipo conceitual de visualização interativa de um hipercubo 4D, feito com HTML, CSS, JavaScript e Canvas, com [demo publicada](https://marcellabongiolo.github.io/ai-4d/).

## Executar localmente

Abra index.html no navegador. O projeto usa HTML, CSS e JavaScript puro e não precisa instalar dependências.

## Publicação

O GitHub Pages publica a pasta raiz da branch main. Para atualizar o site, envie as alterações para essa branch e aguarde o término da publicação em Settings → Pages.

## Personalizar

Atualize os projetos, textos e links em index.html. A paleta e os estilos responsivos ficam em style.css.
