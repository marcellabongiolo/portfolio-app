# Marcella Bongiolo — Portfólio

Portfólio pessoal de Marcella Bongiolo, estudante de Engenharia de Software. O site apresenta projetos de desenvolvimento full-stack, observabilidade para agentes de IA e visualização interativa.

## Projetos em destaque

- [SLADeck](https://github.com/marcellabongiolo/SLADeck) — SaaS full-stack para solicitações de equipe, atribuições e prazos de SLA.
- [AgentTrace](https://github.com/marcellabongiolo/AgentTrace) — SDK Python e painel para rastrear e inspecionar execuções de agentes de IA.
- [AI 4D](https://github.com/marcellabongiolo/ai-4d) — visualização interativa de hipercubo 4D, com [demo publicada](https://marcellabongiolo.github.io/ai-4d/).

## Executar localmente

Abra `index.html` no navegador. O projeto usa HTML, CSS e JavaScript puro e não precisa instalar dependências.

## Personalizar

Atualize os projetos, textos e links em `index.html`. A paleta e os estilos responsivos ficam em `style.css`.
