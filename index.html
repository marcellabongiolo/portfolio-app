01 · FULL-STACK APPLICATIONSLADeck＋

Challenge

Give teams visibility into requests, owners, stages, and deadlines that need attention.

What I built

An application with organizations and team-level permissions, a filtered request inbox, SLA policies, comments, activity history, and operational indicators. Background tasks track deadlines.

Technical decisions

Next.js and TypeScript for the interface; FastAPI for the API; PostgreSQL for data; Redis and Celery for background jobs. Includes tests for business rules and tenant isolation.

Skills demonstrated

Workflow modeling, organization-level authorization, and integration across APIs, databases, and background processing.

02 · DEVELOPER TOOLAgentTrace＋

Challenge

Scattered logs make it difficult to follow a run. This project organizes application-provided telemetry and connects related operations in a trace tree.

What I built

A Python SDK creates nested traces and spans, records events, metrics, duration, and errors, then sends them to an API. A dashboard lets you navigate from runs to span details.

Technical decisions

FastAPI receives and queries data; SQLite provides MVP persistence; Next.js and TypeScript power the dashboard. The repo includes SDK, API, storage, and integration tests.

Skills demonstrated

Telemetry modeling, sync and async instrumentation, API validation, and connecting a Python package to a web interface.

The system records events supplied by the application; it does not capture hidden model reasoning.

03 · INTERACTIVE VISUALIZATIONAI 4D＋

Challenge

How can we make the idea of adding time to three spatial dimensions easier to explore? This prototype turns that question into an interactive browser experience.

What I built

An interactive 4D hypercube visualization with rotations across multiple planes, perspective projection, and pointer and scroll controls.

Technical decisions

HTML, CSS, JavaScript, and Canvas with no UI dependencies. It’s a static experience deployed to GitHub Pages with no build step.

Skills demonstrated

Computational geometry, transformations and projections, pointer interaction, and responsive visualization.

This is a conceptual visualization prototype; it does not run an AI model or make predictions from real data.
