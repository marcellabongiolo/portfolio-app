01 · APLICAÇÃO FULL-STACKSLADeck＋

Desafio

Dar visibilidade às solicitações de uma equipe: responsáveis, etapas e prazos que exigem atenção.

O que foi construído

Uma aplicação com organizações e permissões por equipe, caixa de solicitações com filtros, políticas de SLA, comentários, histórico de atividades e indicadores operacionais. Tarefas em segundo plano acompanham os prazos.

Decisões técnicas

Next.js e TypeScript na interface; FastAPI na API; PostgreSQL nos dados; Redis e Celery nas tarefas assíncronas. Há testes para regras de negócio e isolamento entre organizações.

Competências aplicadas

Modelagem de fluxos de trabalho, autorização por organização e integração entre API, banco de dados e processamento assíncrono.

02 · FERRAMENTA DE DESENVOLVIMENTOAgentTrace＋

Desafio

Logs isolados dificultam acompanhar as etapas de uma execução. O projeto organiza a telemetria fornecida pela própria aplicação e relaciona operações em uma árvore.

O que foi construído

Um SDK Python cria traces e spans aninhados, registra eventos, métricas, duração e erros e envia os dados para uma API. O painel permite navegar da lista de execuções até os detalhes de cada span.

Decisões técnicas

FastAPI recebe e consulta os dados; SQLite mantém a persistência do MVP; Next.js e TypeScript apresentam os traces. O repositório inclui testes do SDK, da API, do armazenamento e de integração.

Competências aplicadas

Modelagem de telemetria, instrumentação síncrona e assíncrona, validação de API e integração de um pacote Python com uma interface web.

O sistema registra eventos fornecidos pela aplicação; não captura raciocínio interno oculto de modelos.

03 · VISUALIZAÇÃO INTERATIVAAI 4D＋

Desafio

Como tornar intuitiva a ideia de incluir o tempo junto às três dimensões espaciais? O protótipo transforma essa pergunta em uma experiência explorável no navegador.

O que foi construído

Uma visualização interativa de um hipercubo 4D, com rotações em diferentes planos, projeção em perspectiva e interação por arraste e rolagem.

Decisões técnicas

HTML, CSS, JavaScript e Canvas sem dependências de interface. É uma experiência estática, publicada no GitHub Pages sem etapa de build.

Competências aplicadas

Geometria computacional, transformações e projeções, interação por ponteiro e visualização responsiva.

É um protótipo conceitual de visualização; não executa um modelo de IA nem faz previsões com dados reais.
